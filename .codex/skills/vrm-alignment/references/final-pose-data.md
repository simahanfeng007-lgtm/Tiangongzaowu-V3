## 文献目标

- JOSR 2022 上肢站立中立位（doi:10.1186/s13018-022-03113-5，upright CT）：
  盂肱外展 4.5°（女 4.9°）、内旋 9.0°（女 8.5°）、肘屈 15.5°（女 15.2°）、
  肘外翻 9.8°（女 10.4°）、旋前 90.2°。
- Lee & Jung 2014（Int J Occup Saf Ergon, PubMed 24629871）休息手：
  MCP≈30°、PIP≈30°、DIP≈10°，小指侧自然加深。
- ScienceDirect 2022《Anatomy and Biomechanics of the Thumb Carpometacarpal Joint》：
  拇指 CMC 静息朝向 ≈ 80° 旋前 / 40° 外展 / 50° 屈曲（相对第 2/3 CMC 轴）。

|---|---|---|---|---|
| Index | -0.4363 (25°) | -0.4189 (24°) | -0.1745 (10°) | +0.030 |
| Middle | -0.5236 (30°) | -0.4712 (27°) | -0.1745 (10°) | 0 |

## 拇指（左右独立标定，非纯镜像）

```
right ThumbMetacarpal = (-0.45, -0.35, -0.20)
right ThumbProximal   = ( 0.00,  0.03, -0.025)
right ThumbDistal     = ( 0.00,  0.00, -0.25)

left  ThumbMetacarpal = (-0.40, +0.35, +0.25)
left  ThumbProximal   = ( 0.00, -0.03,  0.00)
left  ThumbDistal     = ( 0.00,  0.00, +0.20)
```

轴含义：x=CMC 旋前角（左右同号负值）、y=内收/外展、z=屈曲。
实测：指腹上倾 0°（平贴掌心）、掌骨方向归中（右 -0.028 / 左 -0.019）、
指尖距食指线 29–30mm、低于指根 22mm。

## 历史坑（避免回退）

1. 面朝方向：头部网格几何实测 = world +Z；chest 骨骼本地 +Z 是背面。
2. 手指旧代码用 rotation.x 当屈曲 → 只产生扭转，手指从未弯曲。
3. 左手手指骨本地 +X 指向手腕 → 屈曲必须乘 sign，否则反弯。
4. 拇指只调内收/屈曲会“翘”或“插进食指”；必须加 CMC 旋前角（metaX）。
5. 拇指内收 -0.70 过头会插进食指；-0.45→-0.35 区间 + 旋前角才是自然下垂。
