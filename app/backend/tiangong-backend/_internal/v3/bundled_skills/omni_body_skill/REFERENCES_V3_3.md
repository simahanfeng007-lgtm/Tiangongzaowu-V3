# v3.3 参考基准

- Google Search Central: Creating helpful, reliable, people-first content.
- Nielsen Norman Group: Concise, scannable, objective web writing; users scan pages.
- Google Engineering Practices: code review protects long-term code health.
- TikTok Creative Best Practices: early hook and content proposition in first seconds.
- PRISMA 2020 checklist: structured evidence reporting for systematic review style work.
- APMP: proposal/bid profession and best-practice community baseline.

这些基准没有被照搬为内容，而是转化为 v3.3 的结构化 Skill、rubric、QC 动作和返工流程。
