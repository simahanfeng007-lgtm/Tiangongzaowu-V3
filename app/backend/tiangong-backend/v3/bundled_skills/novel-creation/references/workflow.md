# Workflow

For an explicitly managed project, discover the existing folder and read status before creating anything. User-declared chapter count determines plan slots; there is no implicit minimum word count or words-per-chapter formula.

Stage the required record shapes, use assist to observe references and timeline calculations, and compile after structural references are valid. Story inconsistencies are observations for the model and judge, not numeric admission gates. Optional normalize/alignment actions alter the supplied plan only when called deliberately.

Checkout → draft → submit → read back → adversarial review is the chapter loop. The next chapter advances only after its transaction is committed, which is not content approval. If interruption leaves a prepared transaction, run recovery and read actual state/bytes. Never blindly replay creation or overwrite concurrent edits.

Preserve the original blueprint and recorded past. Rebase only future plans with current state identity. At the requested checkpoint, audit storage, read content and obtain a final adversarial decision bound to the latest artifacts and current goal.
