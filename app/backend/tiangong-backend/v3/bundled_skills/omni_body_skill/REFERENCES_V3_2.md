# v3.2 研究基准来源

本包的交付标准参考以下公开方法论与官方资料，落地为工具级质量门和 Skill 流程，而不是照搬原文。

1. APMP Body of Knowledge / proposal best practices：提案管理、客户聚焦、交付物创建、流程管理。
2. Federal Plain Language / Digital.gov：受众明确、清晰、简短、可理解、可使用。
3. Duarte presentation method：受众转变、Big Idea、故事结构、行动号召。
4. Pyramid Principle / consulting deck practices：先结论、后论据、MECE、数据支撑。
5. Google Engineering Practices：代码健康、测试、可读性、审查、长期维护。
6. PRISMA 2020：系统综述报告透明度、检索/筛选/综合/局限。
7. YouTube Shorts / TikTok creative best practices：竖屏、前几秒钩子、声音/字幕、CTA、移动端适配。

## 工具化原则
- 所有标准必须变成可调用的 `qc.*` 或 Skill 流程。
- 工具只返回 evidence，不替模型自主规划。
- 低于交付阈值必须返工，不允许宣称完成。
