# 网络搜索

> 用字典中已就绪的 `web.search` 搜索，以实际返回的来源和链接为依据。

## 调用

```json
{"action": "web.search", "args": {"query": "关键词"}}
```
搜索前可用 `system.action_schema` 查看当前参数。图片需求可检索包含图片的来源网页；当前字典没有独立的图片搜索动作，不得编造调用。

## 失败与阅读来源

搜索失败时保留错误原因，可尝试调整查询；需要阅读全文时使用字典中已就绪的 `http.get`。网络或服务不可用时如实说明缺少的证据，不通过终端绕过执行配置。

## 拿到结果必须做的事

整理成表格，**标题必须挂超链接**：

```markdown
## 搜索：{关键词}
> {引擎} · {N}条

| # | 标题 | 来源 |
|---|------|------|
| 1 | [标题文字](https://实际url) | domain.com |
| 2 | [标题文字](https://实际url) | domain.com |
```

每条结果中的 `url` 字段就是超链接地址，`domain` 是来源域名。**必须逐条挂上，不可只写文字不写链接。**

## 可用 Action

| action | 用途 |
|--------|------|
| `web.search` | 网页搜索 |
| `system.action_schema` | 查询当前参数与就绪信息 |
| `http.get` | 抓全文 |
