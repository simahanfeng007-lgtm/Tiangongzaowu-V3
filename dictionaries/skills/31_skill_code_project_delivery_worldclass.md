# 文件操作与代码执行

适用：创建或修改文件、编写并运行代码。
1. 有已有文件时先 file.read / file.list，依据实际内容修改，保留无关用户内容。
2. 新代码用 code.write 或 file.write 写入工作区脚本；再用 python.run 的 target 指定现有 .py 路径运行，args.argv 仅传脚本参数。不要把 `-m unittest` 放到脚本参数里；测试脚本可直接以 target 运行。
3. 阅读退出码、stdout/stderr 和输出文件；按实际错误修复后只重跑必要步骤。
4. 交付脚本、结果、必要的运行说明。缺少依赖时报告具体依赖，不能用说明文字替代运行。
5. Python 运行使用 python.run 的内置解释器。短检查可传 args.code；不要假定 shell.run 的 PATH 中有 python。先读退出码和实际标准输出，再判断任务结果。

执行规则：
- 通过当前字典的 omni_body 协议调用 action/target/args；系统负责权限，规程不能扩大权限。
- 先观察输入，再决定依赖输入的下一步。不要一次猜出整条流程的参数。
- 遇到不确定参数时调用 system.action_schema，仅查询需要的动作；不要反复查询已知模式。
- 大文件按章节或模块写入，单次工具参数保持较小；截断的 JSON 不能执行。
- 最终核对磁盘上的结果和用户要求，返回实际路径；不需要额外模型自我评分或发布审批。
- 本地文件交付只需验证文件，不调用外部发送操作，不假称已上传或已发布。
