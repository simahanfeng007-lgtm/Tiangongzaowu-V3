# 小说与长篇文字写作

适用：小说、短篇故事、章节写作并保存文件。
1. 根据用户要求明确人物、场景、冲突和篇幅，简单任务直接开始创作。
2. 长篇按章节分别写入，不在一个工具参数内塞入整本书。
3. 回读文件核对标题、段落、结尾和约定字数；连续性检查只针对本次生成的内容。
   文件回读附带字符统计即可用于篇幅核对。需要自定义统计时用 python.run 的 args.code，不假定命令行 PATH 中有 python；不要为已经通过的检查额外引入无关审核步骤。
4. 交付可读的 Markdown/TXT 或用户指定格式。不能只输出大纲后宣称小说完成。

执行规则：
- 通过当前字典的 omni_body 协议调用 action/target/args；系统负责权限，规程不能扩大权限。
- 先观察输入，再决定依赖输入的下一步。不要一次猜出整条流程的参数。
- 遇到不确定参数时调用 system.action_schema，仅查询需要的动作；不要反复查询已知模式。
- 大文件按章节或模块写入，单次工具参数保持较小；截断的 JSON 不能执行。
- 最终核对磁盘上的结果和用户要求，返回实际路径；不需要额外模型自我评分或发布审批。
- 本地文件交付只需验证文件，不调用外部发送操作，不假称已上传或已发布。
