# 本地图片与海报制作

适用：信息海报、示意图、文字图片、本地绘图。
内容依据：先读取输入，用户要求展示的原始数值必须作为可读文字出现在图片中；百分比或归一化图形可以补充，但不能替代原始值。合计从输入计算，保持已声明单位；输入未提供单位时不要自行补充。保存后按这些具体要求核对一次。
1. 根据尺寸、主题和用途设计画面；用 image.create_canvas / image.compose / image.add_text，或写 Python Pillow 脚本。
2. 使用可用中文字体，确保文字完整、对比度和留白。
3. 用 image.info 或图像解码核对尺寸、模式、非空像素；交付真实 PNG/JPEG。
4. 未配置外部图像模型时，不声称能够生成照片级模型图片；本地绘图按用户可接受的方式完成。

执行规则：
- 通过当前字典的 omni_body 协议调用 action/target/args；系统负责权限，规程不能扩大权限。
- 先观察输入，再决定依赖输入的下一步。不要一次猜出整条流程的参数。
- 遇到不确定参数时调用 system.action_schema，仅查询需要的动作；不要反复查询已知模式。
- 大文件按章节或模块写入，单次工具参数保持较小；截断的 JSON 不能执行。
- 最终核对磁盘上的结果和用户要求，返回实际路径；不需要额外模型自我评分或发布审批。
- 本地文件交付只需验证文件，不调用外部发送操作，不假称已上传或已发布。
