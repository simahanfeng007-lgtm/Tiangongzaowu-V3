# 对抗智能体决定任务完成

当前协议为 `tiangong.adversarial-completion.v2`，验证平面 1.48，Store schema v33。
普通字典循环默认由隔离上下文的对抗智能体决定完成；执行者只能提出候选结果。

## 执行与裁决

1. 执行者按原任务、字典和现有权限执行。候选终答暂存，UI 显示执行/复核阶段，未批准前不流出候选答复、摘要或附件。
2. 原始工具观察在裁剪前写入按内容寻址的对象存储；索引绑定 request、run、generation、对象 SHA-256 和长度。裁判得到原要求、用户引导、工作区、当前产物版本、观察摘录、索引与候选答复，可按引用分页读取原文。
3. 裁判返回 `complete`、`continue` 或 `blocked`。继续检查须引用用户要求与实际证据，给出具体补证/修复和可观察的失败条件。裁判没有执行工具，不从文件名推定内容，也不能签发权限。
4. `continue` 通过原续答通道交回执行者，执行者可以修复、补证或用证据反驳。反馈保留在三种原生模型协议历史之外，不伪造工具结果。第三模型的反例建议只有咨询作用，最终只有一个裁判。
5. 批准绑定原任务、用户引导、运行身份、完整观察索引、候选全文、工作区和产物字节版本。变化、取消、重启均使旧批准失效；网关捕获产物时再次核对批准对应的实际字节。空文件经验证后保留为本地成果，不强塞进禁止空对象的附件存储。
6. 未取得有效裁决时保留工作区、原始证据和裁决记录，给出未完成说明；不以异常、调用耗尽、剩余待办为零或迟到响应自动放行。

默认流程不再调用旧 Life completion gate 或 regenerative completion proof 来决定普通任务是否完成。自然语言关键词义务、固定文风/行业质量分不拥有该完成权。工具权限、结构契约、字节完整性、取消、执行期限及 Gateway/P19 的既有状态登记继续执行；领域工具公开的结构化参数契约不等同于全局完成判断。

## 证据与限额

- 初始包展示最近 12 条观察（持久证据合计至多 30,000 字符）和最近 64 项索引。被裁剪的历史仍可从持久索引读取，不将摘录当全文。
- 每页最多 12,000 个 Unicode 字符，每次最多请求 3 页；支持原始观察、完整索引和候选全文。已提供区间、缺口及合法下一页请求显式标记；完整候选未全部覆盖时不能批准。
- 每次调度最多 6 次候选评审、总计 32 次裁判调用，每次候选最多 16 轮取证。短证据单次裁判调用至多 60 秒，估算输入超过 12,000 tokens 时至多 90 秒且给父期限留 5 秒，发起候选评审时剩余不足 40 秒则保持未完成。取消始终有效，超时中的旧调用不与新裁决重叠。
- 执行循环为复核预留 `min(120, max(95, 任务时限×20%), 任务时限×50%)` 秒。输入预算遵守当前端点窗口和输出预留；裁判输出上限随证据量为 8,192 或 16,384 tokens，反例模型上限 8,192 tokens，保留用户与 provider 的推理设置。
- 同一裁判可进行一次严格协议纠正、一次重复取证提示；范围错误反馈明确给出每页限制，不执行额外工具，不扩大原需求，也不因协议错误更换裁判寻找批准。
- `complete` 必须没有未处理 findings、coverage_gaps 或 evidence_requests。系统仅校验协议、引用与绑定，不给内容做规则式语义评分。

证据引用不是读取任意路径的能力；分页不增加执行权限。产物版本扫描拒绝异常文件类型、链接替换或读取期间的版本变化。模型仍可能误判，特别是图片、音频或外部应用缺少真正的内容观察时；接线通过不能当作这些门类的语义质量证明。

## 模型角色与故障切换

角色在运行开始时固定，只使用用户明确配置且具备凭据的模型。不会因同厂商共享密钥而把所有目录别名当成已配置模型。

- 单模型：执行与裁判上下文隔离，不声称错误相互独立。
- 多模型：优先选择不同 provider 的裁判，第三个可用模型提供反例建议；只有一个最终完成裁判，不做多数表决。
- 传输或服务失败最多切换一次到运行开始时固定的备用模型，优先已工作的执行模型。切换有记录，不传递私有推理，不复用旧批准。取消、协议矛盾、预算耗尽不会触发“找另一个模型批准”。

## 显式对照模式

| `TIANGONG_ADVERSARIAL_REVIEW` | 行为 |
| --- | --- |
| `judge`（默认；未知值也按此处理） | 对抗智能体裁决完成 |
| `off` | 旧流程对照，不调用裁判 |
| `shadow` | 旧流程对照，仅记录建议 |
| `advisory` | 旧流程对照并反馈建议，完成权仍在旧流程 |

源码默认值不改变已安装服务的显式配置。完整实施、测试、缓存计量及环境限制见 [实施记录](v3-reliability-implementation.md)。历史 v1 的 30 秒上限、仅摘录证据和 12,000 字符候选拒绝策略已被本页取代。

执行模型的工具 JSON 格式错误只重试尚未执行的回合，最多两次格式修复，使用当前工具 schema，且共享父期限与网络重试总额。每次拒绝与 token 使用保留，解析器不猜测或修补 JSON；不重放已经执行的副作用。
