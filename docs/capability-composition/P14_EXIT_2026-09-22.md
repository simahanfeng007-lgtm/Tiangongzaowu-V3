## 模式切换生命周期

```
OFF（隐式，无文件）
  ↓ initialize_shadow_mode() → v1 SHADOW
SHADOW（新链只产 Plan，旧链执行）
  ↓ 前决齐备 + 操作者决定 → v2 LIMITED
LIMITED（新链登记，旧链执行）
  ↓ 前决齐备 + 操作者决定 → v3 DEFAULT
DEFAULT（新链主路径）
  ↓ 回退（可跳级）→ v4 OFF/LIMITED
```

## 诚实说明

- **SHADOW 模式是安全的初始状态**：新链只产 Plan（plan_only_shadow），零登记零副作用——不改变任何现有行为
- **LIMITED/DEFAULT 需要操作者显式推进**：有冷却期和先决条件，不是自动的
- **生产灰度**：属于 P14-D，需要真实运行环境（R02），本批实现的是机制
