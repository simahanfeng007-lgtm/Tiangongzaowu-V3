## Changes

1. Remove Life Store's import of `runtime_security.path_identity`. Standalone
   Life retains strict existing-parent resolution. The existing Gateway host
   explicitly supplies its native observer through EmbeddedLifeRuntime and
   LifeShadowStore. Bad observations fail before SQLite; failures do not fall
   back to lexical/non-strict resolution. No extra Life store or writer exists.
2. Use the existing physical-path observer for orchestration and Omni Grant
   workspace validation, including subsequent workspace identity comparisons.
   Keep workspace hash normalization and authorization/completion rules.
3. Launch source-observation test subprocesses with isolated Python, no bytecode
   writes and one explicit trusted source directory. Do not import candidate
   modules or trust inherited PYTHONPATH/current-directory modules.
4. Add regressions for standalone Life with execution packages blocked, observer
   failure/invalid output, writer/epoch lease cleanup, trusted host wiring, and
   hostile subprocess module paths. Existing architecture guards are unchanged.
5. Extend the P19 freeze surface to both Life forwarding modules, declare the
   correction in plane 1.6 item 25, refresh via the existing UPDATE_FREEZE
   generator, and regenerate mirrors only with the official sync script.
