# Completion evidence without unsolicited quality gates

Tasks that generated valid files were rejected when a desktop prohibition was
reinterpreted as a desktop output requirement, an input folder became an output
fence, or an unrelated helper script invalidated a successful command receipt.
Optional presentation reviews could also demand an unrequested executive style.

Intermediate actions now go through the native schema, permission and workspace
admission checks without task-quality fences. A helper script, empty scaffold or
partial write is not required to already match the final file's format or length.
Final named outputs, real execution evidence and basic artifact format checks
remain. Explicit project output locations are checked at delivery, while a source
folder is not a project boundary. Desktop mentions no longer relocate filenames.

Office heuristics such as a minimum prose length or all-identical spreadsheet rows
no longer veto completion. Optional `qc.*` review results remain visible as advisory
observations; only directly requested reviews can add completion requirements.
Independent benchmark artifact checks are unchanged.

Command evidence records the submitted program and explicit argument paths. Editing
that program or those files still invalidates the receipt. Adding unrelated source
files does not. Undeclared imports and external state are not claimed to be a full
dependency graph. The same rule is used by incremental state and history replay.

Execution completion does not imply user approval. Composition receipt attribution
and ordered feedback from the companion dictionary-memory repair remain in force.
The full-dictionary code representation is still an external experiment, not the
production default. Verification uses regression failures reproduced from the real
eight-family comparison, including negative cases for missing or corrupt outputs.

DeepSeek V4's auxiliary world-semantic request now uses non-thinking mode within
its existing 2048-token/15-second budget. A real pilot otherwise exhausted the
short budget before returning valid semantic JSON. Main task thinking settings
are unchanged. This is scoped to DeepSeek V4/Flash chat completions; other
providers and thinking-only models retain their existing policy. Protocol:
https://api-docs.deepseek.com/guides/thinking_mode/ .

Verification Plane 1.35 records this authority change and the inherited execution
and memory corrections. No benchmark result is substituted for user approval.
