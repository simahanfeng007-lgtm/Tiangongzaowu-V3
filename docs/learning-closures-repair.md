# 执行经验、L5 与主动探究闭环

字典仍只有原子定义。LLM 按用户语义生成新的 Tool / Skill 组合；本次没有添加预置业务 Skill，也没有增加执行器或记忆数据库。

## 1. 首次失败进入跨任务记忆

- Gateway 登记后的叶子产生 `step.failed` 或 `step.ambiguous`，执行账本落盘后立即经现有 `MemoryCoordinator` 保存 L1 来源与 L3 活跃头。无需等用户认可，也无需用户打开状态页。
- `tiangong.composition-lesson.v1` 是自动观察数据，断言为 `observed`。原 `composition-experience.v1` 仍专门表示用户认可，两者不互相冒充。
- 保存实际动作、参数、错误回执、程序/事件哈希和作用域。稍后同一任务、同一动作、同一目标成功时，记录恢复回执和期间成功的修改步骤。此记录证明后续执行成功，不推断唯一原因或内容质量。结果不明的执行不学习盲目重试。
- 模型在新任务中收到有限的相关经验 DATA，读取新输入并生成新组合。采用经验时声明 `experience_refs`，仍走现有登记、授权、执行、完成检查。复用结果按 Request / Run / Generation 回写。
- 自动记录绑定生命、工作区、动作定义及宿主版本。版本不匹配停止召回，历史证据仍保留。重复回执幂等，后续失败会更新恢复状态。重启通过账本补扫最近 64 个相关任务，每次任务最多记录前 8 个失败；自动召回最多 3 条、24,000 字符，超长调用保存省略标记与哈希，不截成伪代码。
- 尚未登记成执行组合的格式错误不属于这条执行经验通道。它们仍有原来的组合拒绝与本轮纠正记录。

## 2. L5 接入生产事实与同一世界上下文

- 原生工具返回后，宿主绑定实际调用摘要、输入哈希、执行器字节/解释器/字典条件。世界理解的现有入口接收该记录，调用已有 `WorldCognitionFacade` 与证据账本。
- 当前落地的命题是：某原子动作在绑定环境中有独立任务的成功执行观察。它不表示任意输入都成功，也不等于产物得到用户认可。
- 同一任务或同一输入的重复回执共享来源组；不会因为状态刷新、世界版本增多而获得独立票。一次观察只到 C1；满足已有阈值且至少两组独立支持才进入 C2。模型输出、L4 假设、记忆复述、自主探究结果不参与这个执行观察法定数，未降低原稳定性门槛。
- 反例进入已有挑战/复核流程；证据过期、环境改变、支持不足时，不再投放稳定认知。C0 无成功支持时只保留候选与反例，不进入要求 C1 以上支持的 `CHALLENGED`。
- 认知引用与文件、动作、假设在同一 `WorldState` 中物化，通过原来的 `WORLD_CONTEXT_SLOT` 投放。读取检查当前有效证据与精确作用域，不建立第二套上下文权威。
- 独立性仍受用户作用域限制。当前聊天入口的 principal 包含会话与发送者；不同聊天的 L5 证据不直接合票。跨聊天失败经验沿原来的生命 / 工作区私人记忆域复用。

## 3. 主动探究从可解析目标到真实收益

- 知识缺口先解析哈希绑定的目标。当前可自动判定收益的是过期 File 的重新观察，供 Self-Will 选择 `file.hash` / `file.read`。缺少测量方法的语义、因果猜测保留为未解决，不杜撰路径或解决证据。
- Self-Will 只提出一次只读观察，模型决策限时 15 秒；现有 Gateway 独立核对动作、目标、期限，并沿原生命意图和授权链执行。
- 原来 `/life-action/invoke` 漏掉的原生世界回执现已接回。新读取的文件摘要、内容哈希和来源进入 File 新版本；严格匹配 Inquiry / AutonomousIntent / Run / Ticket / Scope 才能关闭对应周期。
- 主动观察绑定账本中的原始请求，核验入口身份、生命和工作区，沿用其会话分区签发新 Ticket。入口用户 principal 与 Life 上下文 principal 分别按原有规则核验，不把两种哈希混为一谈；回执回到原来的世界，而不是新造一个会话世界。
- 自主动作的 Run 使用原有 `derive_run_identity(request_id, 1)` 生成。此前只有合法前缀的自造哈希无法通过内层 Omni admission 的 Run 派生校验；未放宽该校验。
- 只有目标 File 得到本次真实回执支持的新版本，并解除对应缺口时，才记解决与信息收益。无关动作成功、旧引用消失、只有模型宣称解决均为零收益。
- 重复世界版本不重复排同一个开放缺口；一个无可测目标的缺口不阻塞后面的可测目标；过期开放周期回收，零收益使用原退避策略。执行返回但世界回执缺失会关闭为零收益并留原因，不永久占满队列。

## 核心入口

- `src/total_gateway/composition_lessons.py`：执行账本到自动经验。
- `src/total_gateway/composition_experience.py`：召回、跨任务引用与结果回写。
- `src/life_service/composition_memory.py`：沿同一记忆权威保存两类 DATA。
- `src/world_understanding/cognition/runtime.py`：原生事实、独立性、L5 生产投影。
- `src/world_understanding/inquiry/observation.py`：可测目标解析与收益判定。
- `src/world_understanding/active_cognition.py`：周期、期限、去重与回执绑定。
- `src/total_gateway/embedded_backend.py`、`orchestration.py`：现有模型/执行链路接通。

这是受条件约束的学习闭环，不是“犯过一次以后永远不再犯”的保证。真实模型验证与各层自动测试分别记录，不能将构造的边界测试称为实际生产任务。
