## 已落地的接口

- 现有 MCP 配置加入应用关联、环境位置、账号标签、凭据变量引用，以及 stdio/Streamable HTTP。三个原动作承担发现、连接读契约和调用；没有新增独立连接调度器。100 个已登记应用均可查询缺项，发现结果按实际配置返回，配置存在不等于连接成功。
- MCP 原始结果在已知凭据脱敏后保存为工作区内容寻址文件，工具分页、截断和未观察模态显式返回。发出调用后超时/断线/记录失败保留未知结果，经原运行回执传入 Gateway，禁止当作已回滚盲目重试。
- 静态抓取与真实 Chromium 操作的能力说明分开。截图/PDF 使用真实渲染；新增一次真实点击及内容回读，缺浏览器直接失败。输出不得覆盖输入页面，下载不得把截断数据当完整文件。
- SQLite 默认只读由数据库实际执行约束，包含 WITH 写语句、PRAGMA 和 ATTACH 边界；`sqlite.query.run` 明确合并为同参数同权限别名。分页范围、BLOB 编码和 CSV 导出失败可观察。
- `qc.docx.delivery_check` 通用分支改为实际内容预览；显式文档结构契约保留，不产生通用质量评分。普通任务始终经过唯一对抗裁判，旧 off/shadow/advisory 环境设置不再绕回旧完成判断。
- 生命周期、绑定与依赖、调用时授权、目标观察和最近实测分别表达。不能把 `implemented=true` 当成已连接、当前账号可用或业务验收通过。

MCP 当前每个动作独立连接，不支持跨动作保留有状态会话、自动 OAuth 或任意异步 MCP Tasks。外部创建/发送等有副作用的重复调用仍按原账本去重；通用 MCP 的服务端 read-only 注解不授予重放权限。需要持续会话、长作业取消、特定账号和重复实时回读的后端，必须补相应的显式执行契约和真实对象验收后再称支持。

全量清单是逐项需求/绑定/引用投影，不表示全部 779 项原子粒度已经人工语义审定或全部真实任务覆盖。尚需对其余保留定义补实测、权限/副作用等价证明、各门类内容观察、目标原生安装启动和回退证据。缺环境只阻断相关项，整体不计完成。

旧数量验收和模式对照已被新方案取代，原失败/未通过记录不改写。旧组合依版本拒绝语义变化；从原目标及已完成事实重新生成剩余步骤。回退本批应停止新任务、保留账本与产物并恢复上一代码/字典完整版本，不能将结果未知的外部动作自动重放。
