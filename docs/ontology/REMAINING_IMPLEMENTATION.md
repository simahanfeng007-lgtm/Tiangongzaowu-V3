每批记录输入、精确源码/字典、具体调用、实际状态、产物版本、修复链及当前裁判决定。旧固定任务配额仍已取代；全部能力覆盖要求保留。新模块只是原组件内部实现，不新增独立调度器、任务库、世界库、记忆库或质检中心。
