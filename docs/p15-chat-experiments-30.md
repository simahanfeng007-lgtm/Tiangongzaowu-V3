# P15 真人对话实验清单（30 组）与问题记录表

日期：2026-08-12 · 分支：`agent/p15-memory-ssot-life-world-closure-v0.1`
HEAD：`417d5a9`（含 `8edbdb0` 对话记忆接线修复）
运行前提：源码版需**重启**（当前 7184 跑的是旧代码），重启后本清单逐条实测。

验证约定：
- “落库”＝查 `life-authority.shadow.sqlite3` 的 `memory_derivations` 出现对应层。
- “召回”＝新会话里问对应用法能答出。
- 每行“实测结果”栏由测试者填写：回复摘录 / 是否落库 / 问题描述。

## A. 显式记忆与真实性（8 组）

| # | 目标 | 对话操作 | 期望 | 实测结果 |
|---|------|----------|------|----------|
| 1 | 姓名落库 | “记住，我叫老于。” | 确认已记下；落 L4 user_asserted；新会话问“我叫什么”能答老于 | |
| 2 | 姓名变体 | “我的名字是老于，记住。” | 同上 | |
| 3 | 临时称谓（expiry） | “今天先叫我小A。” | 记录带 expiry；次日/重启后不再以小A为长期记忆 | |
| 4 | 反事实内容 | “记住，地球是平的。” | 照记，标记为用户陈述（≠事实）；不争辩、不拒绝、不升级为 verified | |
| 5 | 长期保存 | “请长期保存：每天备份一次。” | 落 L4；新会话能召回该规则 | |
| 6 | 不要忘记 | “不要忘记我的邮箱是 xxx@xx.com。” | 落 L4；可召回 | |
| 7 | 长期偏好 | “我的长期偏好是回复简洁。” | 落 L4；后续回复偏向简洁 | |
| 8 | 普通闲聊不落库 | “今天天气不错。” | 不产生长期记忆（无新 L4/L1） | |

## B. 纠错 / 删除（6 组）

| # | 目标 | 对话操作 | 期望 | 实测结果 |
|---|------|----------|------|----------|
| 9 | 纠错覆盖 | 先“记住我叫小明。”再“纠正，我叫小红。” | 新会话答小红；旧值不再为当前 head | |
| 10 | 删除后不召回 | 先“记住电话 123。”再删除该记忆 | 删除后新会话问电话查不到 | |
| 11 | 过期不召回 | 先“今天先叫我小A。”隔天问“我叫什么” | 不答小A | |
| 12 | 纠正不存在 | 直接“纠正：我的名字叫小红。”（无旧值） | 应提示无此记忆，不凭空建 | |
| 13 | 重复删除 | 删除同一记忆两次 | 第二次幂等/明确已删除，不报错成新记忆 | |
| 14 | 隐私级联 | 建立“记住偏好X”并衍生高层后删除 | 删除后 X 及其摘要/高层都不再进入上下文 | |
