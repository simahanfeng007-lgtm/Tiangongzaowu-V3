----------------------------------------------------------------------
架构目标
----------------------------------------------------------------------
Verification Plane = production-wired as PLAN_BOUND completion
prerequisite。CompletionGate 在 PLAN_BOUND 模式下，只有看到与
plan/predicate/subject/verifier/registry/request/run/generation 全部
一致的 VerificationReadiness 才允许宣布完成。Verification 本身仍然
只产生事实（enforcement=RECORD）——它收紧 Gate，绝不成为捷径。

----------------------------------------------------------------------
PLAN_BOUND Contracts
----------------------------------------------------------------------
VerificationPlanEntry：绑定完整 AcceptancePredicate 身份（predicate_id/
sha256/type + verifier + subject + phase + required flag）；
plan_entry_id 由语义内容确定性派生；entry_sha256 复算。

VerificationPlan：request/run/generation/registry_snapshot_sha256 +
排序唯一 entries；plan ID derived；不可变。

VerificationReadiness：plan 的评估结果——required_entry_count/
satisfied_entry_count/entry_assessments（七态：PASS/FAIL/INCONCLUSIVE/
ERROR/NOT_APPLICABLE/MISSING/RECORD_MISMATCH）/verification_ready/
failure_class。只有全部 mandatory entry 有 PLAN_BOUND PASS Record
才 verification_ready=True。

RuntimeCloseoutEvidence：P18 裸布尔的正式替代——绑定 request/run/
generation/life_id/ticket/root_goal_hash/task_contract_hash/
runtime_blockers+digest/life_gate_allowed/required_evidence_ready/
produced_at_ms/evidence_sha256。只证明 Runtime 局部收口。

----------------------------------------------------------------------
CompletionGate Integration
----------------------------------------------------------------------
CompletionRequirements 新增 verification_mode: Literal["NONE","PLAN_BOUND"]
= "NONE"（默认——旧调用方零变化）。

evaluate() 新增 verification_readiness 参数：
- NONE：传 readiness → error；不传 → 完全保持旧行为
- PLAN_BOUND：必须传；identity/lineage 校验失败 → error；
  core_ready = legacy_core_ready AND verification_ready
- 最终仍 core_ready AND delivery_ready → COMPLETED

CompletionDecision 新增字段：verification_mode/verification_ready/
verification_plan_sha256/verification_readiness_sha256。

----------------------------------------------------------------------
Anti-Double-Authority
----------------------------------------------------------------------
测试证明只有 CompletionGate 持有 can_transition_request_completed：
- 源码级：六个 oracle/验证平面模块 grep 无此字段
- 契约级：VerificationPlan/Readiness 无 outcome/completed/can_transition
