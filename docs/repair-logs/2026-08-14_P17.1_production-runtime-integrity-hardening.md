# P17.1 Production Runtime Integrity Hardening

Date: 2026-08-14 (Asia/Shanghai)

## Scope

P17 M1-M4 封板后的短周期生产加固（不是 P17 返工）。审查发现的结构收口后
暴露出的运行语义边角，按第一性原理修复并全部回归锁定。

## Confirmed findings and fixes

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | Stop 假停止窗口 | stop() 立即写 interrupted 终态，而执行是协作式中断，工具可能仍在产生副作用 | 两阶段状态机：cancel_requested（指令已记录）→ 执行器在检查点 ACK 后 finish() 才落 interrupted 权威终态；无执行者在场（孤儿）时直接终态；前端 runPhaseFromStatus 增加 CANCEL_REQUESTED → "stopping" 非终态映射，cancel() 不再本地掐断请求，等待后端权威终态 |
| 2 | 旧 Confirmation 残链 | pending 端点仍回读磁盘旧记录，而批准端点恒 410 → 永远无法批准的假待办 | pending 通道永久返回空 + retired 标记；历史仅经只读 archive 查询 |
| 3 | Run 身份未 scope-bound | claim 只以 request_id+digest 为键，跨 principal/session 复用 request_id 会串 Run | claim 绑定 immutable principal_scope（session 或显式 scope），scope 不匹配返回 scope_conflict，绝不串 Run |
| 4 | PID 复用误判存活 | 恢复判断只用 _process_is_alive(pid)，PID 复用会让死 Run 永远"活着" | 进程创建 token 租约：claim 记录 owner_start_token（Windows GetProcessTimes / Linux /proc starttime），恢复判断 = PID 存活 AND 创建 token 相等；旧快照无 token 保持历史语义 |
| 5 | 长任务恢复截断 | run snapshot 只存 message[:500]，崩溃恢复快照从此构建 | 新增 message_full（64KB 上限）字段，恢复快照优先用 message_full，旧快照回退 message |
| 6 | Runtime stop 不闭合 | tingzhi 只翻标志，WS serve 循环 wait_closed 永不返回；桥接 HTTP 服务与链路管理器未关闭 | TONGBU.tingzhi 在事件循环上真正 close 服务与连接；DuihuaQiaojie.tingzhi 关闭链路管理器与 HTTP 服务；stop_zongdiaodu_runtime 调用三者 |
| 7 | Windows 保留文件名 | CON.json/NUL 等形态在 Windows 指向设备，request_id 同名文件持久化会失败 | _safe_request_id 检测保留设备名（含扩展名形态），强制 slug--digest；slug 剔除点号防止 lpt3.json--digest 类形态仍命中设备 |
| 8 | Settings 非原子写 | write_text 直接覆盖，掉电产生损坏 JSON 并被静默当默认 | 共享 settings_persistence.atomic_write_json（tmp+fsync+replace，小文件留 .bak）；读路径 read_json_authority 区分 missing/ok/recovered_from_backup/corrupted，损坏时在状态端点显式报 SETTINGS_AUTHORITY_CORRUPTED |
| 9 | /api/v1/sessions 假接口 | 固定返回空数组，前端从未使用 | 删除伪成功端点 |

未处理（按审查结论）：World observer 的 import-time 安装属于后续 lifecycle
migration 技术债，不在本周期返工。

## Adversarial regression

`tests/test_p17_1_runtime_integrity.py`（11 项）已并入永久 Architecture Gate：

- 两阶段停止：执行中 stop → cancel_requested；finish ACK → interrupted；
  孤儿 stop → 立即终态；终态 stop 幂等
- 确认退役：磁盘存在旧 pending 记录时 pending 端点仍返回空
- scope 绑定：跨 session 复用 request_id → scope_conflict；同 scope 幂等
- PID 复用：PID 存活 + 创建 token 不匹配 → 判定死；旧快照回退语义
- 长任务：500 字 preview 之外的完整任务内容进入恢复快照
- Windows 保留名：CON/NUL/COM1/lpt3.json 等全部落入 digest 形态
- 设置权威：原子写无 .tmp 残留、.bak 滚动、损坏显式报错、损坏从 .bak 恢复
