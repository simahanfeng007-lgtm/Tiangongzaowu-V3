# 生产语义层自动绑定当前模型

2026-09-25，当前修复分支实现。V3 的生产世界语义层现在会复用调度器已经持有的模型客户端，并在每次允许的语义调用前读取当前生效的模型配置。

后续已完成动态字典投影、假设正文持久化、锁外推断、逐轮上下文刷新和组合记忆回接，见 [统一修复记录](world-dictionary-unified-repair.md)。本文以下测试和待办描述保留为自动绑定初期的阶段记录。

此后首次失败记忆、L5 执行观察归集与文件主动探究闭环也已接通，当前范围与验收边界见 [学习闭环修复](learning-closures-repair.md)。

## 运行方式

1. `runtime_composition.build_zongdiaodu_composition()` 创建原有 `HttpKehuduan` 后，自动注册弱引用。没有创建第二套 HTTP 客户端、密钥配置或执行入口。
2. `world_understanding_production` 为生产 `SemanticPipeline` 注入 `ConfiguredWorldSemanticModel`。初始化本身不调用模型，也不要求客户端和凭据已经就绪。
3. 每次调用前解析当前 provider、模型、Base URL 和协议，检查该端点的原有凭据。后续切换配置会在下一次获准调用时生效；无配置时不选择其他供应商兜底。
4. 一次调用固定所解析的端点快照，防止调用过程中再次读取配置导致模型身份与实际请求不一致。
5. 通过已有 `V3HttpSemanticModel` 请求结构化假设，仍由原有 P8 解析和引用校验逻辑验证，再通过原有世界状态物化路径保存。

语义调用的工具表为空，同时清空当前任务的原生历史、音频输入，并跳过任务技能上下文。调用结束后恢复原调用上下文。推理输出仍然是假设，不是已验证事实、稳定认知或执行授权。

## 默认预算

| 控制 | 默认行为 |
|---|---|
| 单次等待 | 最多 15 秒，同时受当前主调用和 Gateway 剩余期限约束 |
| 每次执行 | 同一世界作用域、principal、run 和 generation 最多尝试 1 次 |
| 连续调用 | 同一世界作用域和 principal 间隔至少 30 秒 |
| 生成预算 | 最多 2048 tokens，具体协议字段由原 transport 转换 |
| 输入预算 | 64000 字符，超额时延期，不截断引用后继续推理 |
| 网络重试 | 一次尝试；不触发面向工具调用的截断修复提示 |
| 故障处理 | 超时、缺配置、非法结果不阻止基础事实物化 |

这是同步辅助推理；默认单次执行最多增加约 15 秒的模型等待，并非完全没有延迟。计数在进程内保存且有容量上限；重启后重新累计。

语义推理使用现有模型调用生命周期的子期限：子调用超时不会取消仍有效的父调用；父调用取消仍约束子调用。若底层网络或 DNS 忽略取消而迟迟没有退出，迟到结果不会入库，且在原调用真正退出前不再启动新的语义调用线程。

`TIANGONG_WORLD_SEMANTIC_ENABLED=0` 可关闭此辅助推理。未设置时自动启用；没有可用的原客户端或凭据时仍保留基础事实链路。

## 诊断

现有 `tiangong.world_semantic` 日志输出状态、原因码、模型描述符、假设数量和延迟，不输出密钥或原始记录正文。预算延期与模型不可用分开表示：

- `COMPLETED`：模型结果通过原有假设解析。
- `NOT_ADMITTED`：调用预算、冷却、输入上限或在途调用限制使本次推理延期。
- `LLM_UNAVAILABLE`：客户端、配置、网络、期限或取消导致不可用。
- `OUTPUT_REJECTED`：模型已返回，但结果没有通过假设契约校验。
