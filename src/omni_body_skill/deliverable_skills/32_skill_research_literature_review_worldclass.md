# 世界顶尖级资料/论文综述 Skill

## 设计依据
参考 PRISMA 2020 对系统综述透明报告的要求：说明为什么做、怎么检索、怎么筛选、怎么综合、局限是什么。普通资料综述也按这个精神降级使用。

## 输入契约
- 研究问题
- 关键词/主题
- 时间范围
- 来源类型
- 排除范围
- 输出格式

## 工具流程
1. 明确研究问题和关键词。
2. 如果宿主有搜索工具，先搜索；如果没有，只能处理本地资料，不得假装联网。
3. `research.evidence_table.create` 建证据表。
4. 读取 PDF/网页/文档，提取方法、样本、结论、局限。
5. 写综述，不罗列，要综合共识/分歧/证据强度。
6. `qc.research.evidence_check` 检查搜索策略、筛选、证据表、引用、局限。
7. 分数低于80则 `repair.plan` 并返工。

## 顶尖交付标准
- 研究问题明确。
- 来源可追溯。
- 有纳入/排除标准。
- 有证据表。
- 结论区分事实、推断和不确定性。
- 明示局限性。

## 验收
- `qc.research.evidence_check.score >= 80`。
