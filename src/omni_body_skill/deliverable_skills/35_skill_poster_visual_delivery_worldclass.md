# 海报 / 图片生成

> 通过 LLM 内置生图能力（MiniMax image-01 / OpenAI gpt-image-1）直接生成。

## 快速路由
用户要海报/制图/图片 → `image.generate` 直接生成。不要多步。

## 用法
```json
{"action": "image.generate", "args": {"prompt": "详细的图片描述", "size": "1024x1024"}}
```

### 参数
- `args.prompt` — 图片描述，越详细越好
- `args.size` — 尺寸：1024x1024 / 1280x720 / 720x1280 等
- `args.style` — 可选，风格提示

### 海报 prompt 模板
```
{主题}海报，竖版，{风格}风格，{配色}配色，
标题文字「{标题}」，副标题「{副标题}」，
{关键视觉元素}，高清，专业排版
```

### 生图完成后
- 文件路径用 `MEDIA:` 前缀发给用户
- 不要生成多张，一次一张，用户满意再继续
